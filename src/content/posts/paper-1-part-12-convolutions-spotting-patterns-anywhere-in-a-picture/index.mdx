A fully-connected neural network flattens an image into a long vector and applies weights to every pixel independently.

This ignores a key property of images: **locality**. Important patterns are usually local. An eye is a small region. A texture is a repeating pattern over nearby pixels. Connecting every pixel to every neuron, the way a fully-connected layer does, can't exploit this.

**Convolution** does. A convolution slides a small filter (like a 3×3 grid) across the image, and at each position computes the dot product between the filter and the image region under it (multiply each filter number by the pixel beneath it, then add them all up).

## A Concrete Example

Imagine a 5×5 image and a 3×3 filter:

```
Image:                Filter:
10 10 10 10 10        0 -1  0
10 50 10 10 10       -1  4 -1
10 10 10 10 10        0 -1  0
10 10 10 10 10
10 10 10 10 10
```

Place the filter at position (0,0) and multiply element-wise with the image region:

```
(10*0 + 10*-1 + 10*0 + 10*-1 + 50*4 + 10*-1 + 10*0 + 10*-1 + 10*0) = 200 - 40 = 160
```

This gives one output value, 160: a big response, because the filter is centered on the bright spot. (Over a flat patch of all 10s, the same filter would give 0, so it lights up only where the pattern it detects appears.) Slide the filter one pixel to the right and repeat. Slide down and repeat. After sliding everywhere, you get a smaller output map.

With a 3×3 filter and no padding, the output is 2 pixels smaller in each dimension, since the filter can't slide off the edges. Adding a border of zeros around the image, called **padding**, keeps the output the same size.

## What the Filter Learns

The weights in the filter are learned (like weights in a fully-connected layer). After training, filters often learn to detect specific features:
- Edge filters (horizontal, vertical, diagonal edges)
- Texture filters (corners, blobs)
- More complex patterns in deeper layers

Multiple filters run in parallel. A layer might have 32 filters, each detecting different patterns. The output is a 3D stack of 32 feature maps.

## Why Convolution Works

**Local receptive fields:** Each output pixel depends only on a small region of the input. Patterns don't need to be globally aligned.

**Parameter sharing:** The same filter slides everywhere. This dramatically reduces the number of parameters compared to fully-connected layers.

**A filter works everywhere:** because the same filter slides across the whole image, it spots its pattern wherever that pattern appears, so the network doesn't have to learn it separately for each location. (Making the output fully unaffected by position takes one more step, pooling, in Part 13.)

Together, these let a convolutional layer find patterns anywhere in an image with far fewer parameters than a fully-connected layer.
