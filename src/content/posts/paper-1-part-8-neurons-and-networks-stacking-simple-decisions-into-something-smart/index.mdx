From Part 4: a linear classifier computes a weighted sum of pixels and picks the highest score.

The problem: one linear layer can only learn linear decision boundaries. If your classes aren't linearly separable (and most real-world data isn't), you're stuck.

The solution: **neural networks**. Stack multiple layers, add non-linearity between them, and suddenly you can learn curved boundaries and complex patterns.

## The Neuron

A **neuron** is the basic unit. It takes inputs, multiplies them by weights, adds a bias, and applies an **activation function**.

```
output = activation( (w1*x1 + w2*x2 + ... + bias) )
```

The activation function is non-linear. Common ones:

**ReLU (Rectified Linear Unit):**
```
f(x) = max(0, x)
```
If the sum is positive, pass it through. If negative, zero it out. Dead simple and widely used.

**Sigmoid:**
```
f(x) = 1 / (1 + e^(-x))
```
Squashes any input to a value between 0 and 1. Historically popular.

**Tanh:**
```
f(x) = (e^x - e^(-x)) / (e^x + e^(-x))
```
Squashes to between -1 and 1. Roughly a shifted sigmoid.

The key: without the activation function, stacking linear layers just gives you another linear layer (linear of a linear is linear). The activation function breaks this chain and allows the network to learn non-linear patterns.

## Stacking Layers

Here's the magic: stack multiple layers, each with its own weights and activation:

```
Input (pixels)
  → [Linear layer 1] → [ReLU] 
  → [Linear layer 2] → [ReLU]
  → [Linear layer 3] → [ReLU]
  → [Linear layer 4 - final scores]
```

Each layer transforms the data. The first layer learns low-level patterns. The second layer learns combinations of those patterns. The third layer learns higher-level concepts.

By the time you reach the final layer, you've built up enough abstraction to solve complex problems.

## Why This Works

With one linear layer, you can only draw straight lines to separate classes. With two layers plus activation, you can draw curves. With three layers, you can draw arbitrarily complex shapes.

More layers = more expressive power. But also more parameters to learn and more risk of overfitting (we'll talk about this in Part 10).

## The Universal Approximation Theorem

There's a mathematical result that says: a neural network with just one hidden layer, given enough neurons, can approximate any continuous function.

This is powerful. It means neural networks aren't limited by architecture—they're limited by:
1. Having enough neurons
2. Having enough data to learn the patterns
3. Finding the right weights through gradient descent

It doesn't say you need just one hidden layer. Multiple layers often learn more efficiently and generalize better.
