From Part 7: gradient descent adjusts weights using gradients (slopes). But how do you compute gradients for a complex function with thousands of weights?

**Backpropagation** is the algorithm that does this efficiently. It's the standard way gradients get computed in deep learning, and it's based on one idea: the chain rule from calculus.

## The Chain Rule

If you remember your high-school calculus: when a function is built from nested functions, the chain rule tells you how to compute its derivative.

```
If y = f(g(x)), then dy/dx = (dy/dg) * (dg/dx)
```

Example: if `y = (x + 5)²`

You can break it down:
- `g(x) = x + 5`
- `f(g) = g²`

Then:
- `dg/dx = 1` (the derivative of addition)
- `df/dg = 2g` (the derivative of squaring)
- `dy/dx = (2g) * (1) = 2(x + 5)`

The chain rule turns one complex derivative into a product of simple, local ones, which is what lets you break the problem into manageable pieces.

## The Assembly Line Metaphor

Imagine a factory assembly line. A component moves through several stations:

```
Input → [Station A] → [Station B] → [Station C] → Output
```

At each station, workers add value (or subtract it). The final output depends on what happened at every station.

Now imagine the output is wrong. Quality control finds a defect. Who's to blame?

The blame isn't the output's responsibility alone. Blame propagates backward through the line:
- "Why is the output bad? Because Station C did bad work, or because the input to Station C was bad."
- "Why was the input to Station C bad? Because Station B did bad work."
- "Why was Station B's output bad? Because Station A did bad work, or because the original input was bad."

Each station needs to know: "How much of the final defect is my fault?"

Backpropagation does exactly this for a neural network: it works out how much each weight is to blame for the loss, passing blame backward through the function.

## How Backpropagation Works

A linear classifier is really just one step, multiply the pixels by weights and add the biases, followed by computing the loss:

```
Input (pixels) → [multiply by weights, add biases] → [compute loss]
```

Each box is a "station" that produces an output from an input.

Backpropagation works in two passes:

**Forward pass:** Feed the input through the entire function, computing outputs at each station. Save the intermediate results.

**Backward pass:** Starting from the output loss, work out how much the loss would change if each station's output changed a little. That number is the station's "blame." Use the chain rule to propagate it backward through each layer.

At each station, blame flows backward by multiplying two numbers:
- **Incoming blame:** how much the final loss changes if my output changes a little (say, 2.5).
- **My local effect:** how much my output changes if my input changes a little (say, 1.2).
- **Blame I pass back to my input:** 2.5 × 1.2 = 3.0.

By the time you reach the weights, you know exactly how much each weight affects the final loss.

## Why This Is Fast

If you estimated the gradients numerically (nudge each weight a tiny bit, rerun, and see how much the loss changed), you'd need to:

1. Change weight #1 by 0.0001, run the full forward pass, measure the loss change → gradient for weight #1
2. Change weight #2 by 0.0001, run the full forward pass, measure the loss change → gradient for weight #2
3. Repeat for all 3,000 weights

That's 3,000 full forward passes, one for every weight, and real networks have millions of them.

Backpropagation does it in one forward pass and one backward pass, no matter how many weights you have.

The chain rule means: once you've computed blame at one layer, you can quickly compute blame at the previous layer. You multiply by the chain rule factor and move on.

## What Backpropagation Comes Down To

Backpropagation isn't magic. It's just:

1. The chain rule from calculus
2. Applied systematically to a layered function
3. In reverse order (backward)

What makes this work: each layer only needs to know its own local behavior (how its output depends on its input). It doesn't need to understand the entire function. The chain rule automatically propagates local information backward into global gradients.

This is why neural networks can have hundreds of layers. Each layer is independent and local. Backpropagation connects them all.
