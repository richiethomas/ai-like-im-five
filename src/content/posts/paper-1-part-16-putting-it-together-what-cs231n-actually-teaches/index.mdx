Let's trace a complete example: classifying a cat image.

## The Pipeline

**Step 1: Input**

Raw image: 224×224 pixels, each with 3 color channels (RGB), so the input is a 224×224×3 block of values, each from 0 to 255.

First thing: normalize. Divide by 255, or standardize using ImageNet statistics. Normalized image: same shape, values now in a sensible range.

**Step 2: Early Convolutions**

First convolutional layer: 64 filters, each detecting simple patterns (edges, corners, colors).

Each filter spans all three color channels: a 3×3 filter is really 3×3×3, covering a small patch across red, green, and blue at once. Slide it across the image, and at each position it multiplies those 27 values by its weights and sums them into a single number. So one filter produces one 2D feature map, not three. (This is the same depth-spanning idea from [Part 12](/post/paper-1-part-12-convolutions-spotting-patterns-anywhere-in-a-picture/), where a deeper filter spans all the feature maps beneath it; here the depth is just the 3 color channels.)

Output: 64 feature maps, 224×224. (Padding the edges keeps the size the same; without padding it would be 222×222.)

Apply ReLU activation: set negative values to zero.

Pool with 2×2 max pooling: output becomes 112×112.

Result: 64 feature maps of edges and simple patterns.

**Step 3: Intermediate Convolutions**

Second convolution: 128 filters, applied to the 64 input maps.

These filters detect combinations of edges: textures, blobs, more complex patterns.

Output: 128 feature maps, 112×112.

ReLU, then 2×2 pooling: 56×56.

Repeat: more convolutions, more pooling, increasing complexity and decreasing size.

By layer 5: perhaps 512 feature maps, 7×7.

Each map detects high-level concepts: object parts, shapes, semantic features.

**Step 4: Classification**

Flatten the 512×7×7 maps into a vector: 512*49 = 25,088 values.

Pass through fully-connected layers:
- Dense layer 1: 4096 neurons, ReLU
- Dense layer 2: 4096 neurons, ReLU
- Output layer: 1000 neurons (one per ImageNet category)

During training, dropout (randomly zeroing 50% of the neurons) is applied to these dense layers to prevent overfitting.

Apply softmax, which turns the raw scores into probabilities that add up to 1. If the cat is clearly visible, the "cat" neuron fires strongest, and softmax returns ~0.99 for cat, ~0.01 split among others.

**Step 5: Inference**

The predicted class is whichever output neuron has the highest probability (its argmax), here "cat".

Network predicts "cat" with 99% confidence.

## Why This Works

**Hierarchy:** Early layers learned low-level features (edges). Middle layers combined them into medium-level features (textures). Late layers combined those into high-level features (objects).

By the final convolutional layers, each location in the feature maps encodes something high-level, like "there's a cat face around here." The fully-connected layers then weigh all of that together to make the call.

**Robustness:** Pooling and convolutions make the network robust to small shifts. A cat's whiskers don't have to be at pixel-perfect positions.

**Generalization:** Regularization (dropout, and weight decay, a penalty on large weights) prevents the network from memorizing specific training images. It learns generalizable patterns.

**Transfer learning:** If you're fine-tuning a pre-trained network, the early layers already recognize edges and textures. You only need to train the late layers to recognize your specific categories.

## Why CS231n Matters

CS231n teaches this entire pipeline from scratch. You don't just use a library; you understand:

- Why architecture matters
- Why data preparation matters
- Why regularization matters
- How backpropagation trains weights
- What the network actually learns

This understanding transfers to other domains. Ideas move between fields: the transformer architecture that reshaped language processing was later adapted to images too. And principles like overfitting and regularization apply everywhere.

CS231n is foundational because it builds intuition. Once you understand how a CNN works, adapting it to new tasks or understanding new architectures is straightforward.
