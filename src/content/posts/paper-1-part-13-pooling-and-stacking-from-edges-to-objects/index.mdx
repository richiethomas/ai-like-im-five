After a convolution layer, feature maps are the same size as the input (or slightly smaller). If the input is 224×224, the output might be 222×222.

Apply another convolution, get 220×220. Keep going and the maps stay large, the computation piles up, and each convolution still only sees a small local patch.

**Pooling** solves this. It downsamples: takes a region (like 2×2) and outputs a single value. Common pooling: **max pooling**. Take the maximum value in each 2×2 region.

```
Input:           Max Pooling (2×2):
1 2 3 4          6 8
5 6 7 8    →     14 16
9 10 11 12
13 14 15 16
```

Output is half the size in each dimension. A 224×224 map becomes 112×112.

## Why Pooling Works

**Aggregation:** Pooling combines information from a small region into one value. Within that region the exact position stops mattering; what carries forward is mainly whether the feature is present.

**Robustness:** if a pattern shifts by a pixel or two, max pooling often gives the same result, since the largest value in the window is usually still the largest. That makes the network more tolerant of small shifts, which helps recognition. (The flip side: pooling blurs away exact positions, so it's less suited to tasks that need to locate things precisely.)

**Dimensionality reduction:** Smaller feature maps = faster computation.

## The Hierarchy

Stacking convolution and pooling layers builds a hierarchy:

```
Input image (224×224)
  ↓ Conv (detect edges)
  ↓ Pool (224→112)
  ↓ Conv (detect edge combinations, i.e., textures)
  ↓ Pool (112→56)
  ↓ Conv (detect texture combinations, i.e., shapes)
  ↓ Pool (56→28)
  ↓ Conv (detect complex shapes, i.e., object parts)
  ↓ Pool (28→14)
  ↓ Fully connected layers (make the final decision)
```

Early layers detect simple features. Later layers detect complex combinations. By the time you reach a fully-connected layer, you're working with high-level features (combinations that respond to things like shapes and object parts) rather than raw pixels.

Loosely speaking, a cat classifier ends up responding to a particular combination of these features: certain edges here, certain textures there, together adding up to "cat" (not a rule written in words, but a pattern of numbers that behaves like one).
